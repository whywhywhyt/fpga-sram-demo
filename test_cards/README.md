# 固定颜色与形状测试图

双击 known_colors_shapes.html，在电脑浏览器本地打开。不联网，不访问摄像头、USB或开发板，不改变FPGA工程。

固定颜色：红(220,32,32)、黄(220,192,32)、绿(32,180,64)、蓝(32,64,220)；背景(192,192,192)。提供圆形、三角形、矩形，单色/四色同屏、空背景、慢速移动、全屏图卡。用于后续统一屏幕目标的输入，避免原色块RGB未知；不是用于拟合物理颜色的标准色卡。

推荐先实体白纸校色，再固定屏幕亮度/色彩设置/机位，在原图和识别模式测试4×3组合；空背景检查误框，实体红块复测移动坐标。图卡的形状位置属于网页坐标，不等于相机/目标框的坐标。保持相同CAL和增强状态比较版本；噪点、偏色、形状及边框稳定性分别记录。

可保存固定测试入口，例如：

- `known_colors_shapes.html?color=blue&shape=circle`
- `known_colors_shapes.html?multi=1&shape=triangle`
- `known_colors_shapes.html?blank=1`

控制面板在图卡外，全屏模式只呈现目标和中性灰背景，避免彩色按钮进入摄像视场。
